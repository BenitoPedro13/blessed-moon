# Keyboard keypresses

32 single keypresses from **Keyboard Soundpack #1** by unicaegames, CC0
(https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes).
Cherry KC 1000, recorded with a Shure SM7B. Converted to mono 48kHz WAV.

Used only by `scripts/social-story-video.mjs` for the typing sound in Story videos;
not served by the site.
